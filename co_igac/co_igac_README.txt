# co_igac_README.txt

The files in this section result from the conversion of datasets originating
from [IGAC](https://www.igac.gov.co/)

## Included grids

### Colombian vertical grid:

*Source*: [IGAC](https://www.isgeoid.polimi.it/Geoid/America/Colombia/public/Gravimetric_QGeoidCOL2023.txt)
*Format*: XYZ
*License*: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
*Credit*: (c) Instituto Geográfico Agustín Codazzi - Colombia
*Horizontal CRS*: EPSG:20045 (MAGNA-SIRGAS 2018)

Vertical transformation for Geoid model QGeoidCOL2023. Used to make the transition
from heights in vertical CRS COLGVD2023 height (EPSG:11513)
to heights above the ellipsoid in MAGNA-SIRGAS 2018 (EPSG:20045).

* co_igac_QGeoidCOL2023.tif
